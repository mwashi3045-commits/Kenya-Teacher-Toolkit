# Kenya Teacher Toolkit — CBE assessment update

The toolkit supports four learning bands with band-specific grades and subjects:

- Lower Primary: Grades 1–3
- Upper Primary: Grades 4–6
- Junior School: Grades 7–9
- Senior School: Grades 10–12

A dedicated `assessment.html` tool now provides the eight-level classroom scale used by this implementation:

| Level | Code | Broad band | Range |
|---:|---|---|---|
| 8 | EE1 | Exceeding Expectations | 90–100% |
| 7 | EE2 | Exceeding Expectations | 75–89% |
| 6 | ME1 | Meeting Expectations | 58–74% |
| 5 | ME2 | Meeting Expectations | 41–57% |
| 4 | AE1 | Approaching Expectations | 31–40% |
| 3 | AE2 | Approaching Expectations | 21–30% |
| 2 | BE1 | Below Expectations | 11–20% |
| 1 | BE2 | Below Expectations | 1–10% |

The descriptors are criterion-referenced classroom guidance. Schools should verify the current KICD/KNEC reporting template and approved score boundaries before using the tool for official national submissions, because assessment guidance and reporting templates can be revised.

Open `assessment.html` from the repository to use the assessment calculator.
