# Kenya Teacher Toolkit A mobile-friendly, offline-first teaching toolkit for Kenyan classrooms. This app helps teachers: - plan lessons aligned to CBC/CBE learning outcomes - track continuous assessment and score performance - build learner progress reports - save everything locally in the browser - export and import workspace data as JSON - print lesson plans and reports for classroom use ## Features - Lesson planner with learning area, grade, topic, outcome, activities, resources and duration - Assessment tracker with percentage calculation and performance feedback - Learner report builder for term progress summaries - Dashboard with live totals and average score stats - Local persistence using `localStorage` - JSON export/import for a portable teacher workspace - Mobile-friendly, responsive layout ## Run locally This is a dependency-free static app. You can open `index.html` directly in a browser or run a local server: ```bash python3 -m http.server 8000 ``` Then visit: ```text http://localhost:8000 ``` ## Test the score calculator Open the browser test page: ```text http://localhost:8000/tests/ ``` or open `tests/index.html` directly. ## Data model The app stores lesson plans, assessment entries and learner reports in browser storage. You can export the complete workspace to a JSON file and re-import it later. ## Suggested next phase Add a real backend for teacher accounts, school-wide data, PDF export, M-Pesa premium features, and optional AI lesson generation once the privacy and security model is ready.
