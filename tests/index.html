# Kenya Teacher Toolkit A KICD-aligned, mobile-friendly curriculum planning app for Kenyan schools. ## What this app includes - Four KICD-style curriculum bands: - Lower Primary: Grade 1–3 - Upper Primary: Grade 4–6 - Junior School: Grade 7–9 - Senior School: Grade 10–13 - Subject sets for each band - Lesson plan generation based on CBC/CBE structure - Lesson notes generation - Scheme of work generation - Record of work generation - Report card generation using KICD-aligned performance levels: - EE = Exceeding Expectation - ME = Meeting Expectation - AE = Approaching Expectation - BE = Below Expectation - Local browser save/export/import support - Print-ready document templates ## Run locally This is a dependency-free static web app. ```bash python3 -m http.server 8000 ``` Then open: ```text http://localhost:8000 ``` ## Notes The app is designed as a robust offline-first curriculum workspace. It uses browser local storage and can export/import JSON files for backup and sharing. ## Suggested next phase Integrate a real backend for school accounts, teacher management, term analytics, and export to PDF/Word once the required privacy, security and compliance model is ready.
